# Визитная карточка API

Тестовый проект

## Зависимости

* Node.js 22.22 и выше
* npm 10.9 и выше
* PostgreSQL 17

## Подготовка проекта к запуску/сборке

1. Установите зависимости

```bash
npm ci
```

2. Проверьте и настройте переменные окружения при необходимости в `.env`.

*Для переопределения переменных окружения создайте `.env.local`*

## Запуск Dev

1. Подготовьте проект. Смотри [Подготовка проекта к запуску/сборке](#подготовка-проекта-к-запускусборке)

2. Запустите проект командой:

```bash
npm run start:dev
```

либо через docker-compose:

```bash
npm run docker:dev
```

## Запуск Prod

1. Подготовьте проект. Смотри [Подготовка проекта к запуску/сборке](#подготовка-проекта-к-запускусборке)

2. Запустите проект командой:

```bash
npm run start:prod
```

либо через docker-compose:

```bash
npm run docker:prod
```

## Сборка

1. Подготовьте проект. Смотри [Подготовка проекта к запуску/сборке](#подготовка-проекта-к-запускусборке)


2. Для сборки проекта выполните команду:

```bash
npm run build
```

Собранный проект будет находится в директории `dist`

## БД

### Установка миграций в БД

```bash
npm run prisma:deploy
```

### Инициализация БД

```bash
npm run prisma:seed
```

Данные для инициализации находятся в `prisma\data.json`
